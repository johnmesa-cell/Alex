🚀 ENDPOINTS DISPONIBLES AHORA MISMO
═══════════════════════════════════════

POST /api/auth/register
  └─ Registra un nuevo usuario
  ├─ Body: { nombre, correo, password, idrol (opcional) }
  └─ Respuesta: { success, message, data }

POST /api/auth/login
  └─ Autentica un usuario y retorna JWT
  ├─ Body: { correo, password }
  └─ Respuesta: { success, message, data con TOKEN }

POST /api/auth/logout
  └─ Cierra la sesión (Requiere autenticación)
  ├─ Header: Authorization: Bearer <token>
  └─ Respuesta: { success, message }

🔑 CÓMO USAR EN TUS RUTAS
═════════════════════════

Importa el middleware:
  import authMiddleware from '../middlewares/auth.middleware.js';

Ruta protegida (requiere token):
  router.get('/ruta-protegida', 
    authMiddleware.verifyToken, 
    tuControlador
  );

Ruta con validación de rol (solo admin):
  router.post('/solo-admin',
    authMiddleware.verifyToken,
    authMiddleware.verifyRole(['admin']),
    tuControlador
  );

Ruta con múltiples roles:
  router.delete('/eliminar',
    authMiddleware.verifyToken,
    authMiddleware.verifyRole(['admin', 'moderador']),
    tuControlador
  );

Acceder al usuario autenticado:
  router.get('/mi-data', authMiddleware.verifyToken, (req, res) => {
    console.log(req.usuario);  // { idusuario, correo, nombre, idrol, nombrerol }
    console.log(req.token);    // JWT completo
  });

     -H "Content-Type: application/json" \
     -d '{

       "password": "Test123456"

4. Copia el token del login y úsalo:
