# Carpeta para archivos de audio de prueba
En esta carpeta puedes colocar tus archivos .mp3 para probar el endpoint /api/asistente-voz.

## Instrucciones para probar:
1. Coloca tu archivo `mp3` aquí.
2. Asegúrate de tener el servidor corriendo.
3. Usa el archivo `pruebas.http` para enviar la petición.
