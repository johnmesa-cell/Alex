┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔐 FUNCIONALIDADES IMPLEMENTADAS                                           │
└─────────────────────────────────────────────────────────────────────────────┘

    1️⃣  REGISTRO (POST /api/auth/register)
        └─ Validación de email (RFC 5322)
        └─ Validación de contraseña (mín 6 caracteres)
        └─ Cifrado bcrypt (10 rounds)
        └─ Detección de duplicados
        └─ Respuesta JSON clara

    2️⃣  LOGIN (POST /api/auth/login)
        └─ Verificación de credenciales
        └─ Generación JWT (24 horas)
        └─ Registro de sesión en BD
        └─ Captura IP y User-Agent
        └─ Actualización último login

    3️⃣  LOGOUT (POST /api/auth/logout) [PROTEGIDO]
        └─ Requiere token válido
        └─ Marca sesión como expirada
        └─ Limpia estado

    4️⃣  VERIFICACIÓN DE TOKEN
        └─ Middleware verifyToken
        └─ Valida header Authorization Bearer
        └─ Decodifica JWT
        └─ Expone req.usuario

    5️⃣  VALIDACIÓN DE ROLES
        └─ Middleware verifyRole
        └─ Permite múltiples roles
        └─ Respuesta 403 si no autorizado

│ 🔑 CÓMO PROTEGER TUS RUTAS                                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    Ejemplo 1: Ruta Protegida (requiere token)
    ─────────────────────────────────────────
    import authMiddleware from '../middlewares/auth.middleware.js';

    router.get('/mi-perfil',
      authMiddleware.verifyToken,
      (req, res) => {
        console.log(req.usuario);  // { idusuario, correo, nombre, idrol, nombrerol }
        res.json({ message: 'Datos del usuario', user: req.usuario });
      }
    );


    Ejemplo 2: Ruta Solo Admin
    ──────────────────────────
    router.delete('/eliminar-usuario/:id',
      authMiddleware.verifyToken,
      authMiddleware.verifyRole(['admin']),
      (req, res) => {
        // Solo admins pueden llegar aquí
      }
    );


    Ejemplo 3: Ruta Para Múltiples Roles
    ────────────────────────────────────
    router.post('/crear-contenido',
      authMiddleware.verifyToken,
      authMiddleware.verifyRole(['admin', 'moderador', 'editor']),
      (req, res) => {
        // Admin, moderador y editor pueden acceder
      }
    );

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎯 INFORMACIÓN IMPORTANTE                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    Campo de contraseña: Se guarda como "passwordhash" (no "password")
    Campo de ID: "idusuario" (no "id")
    Campo de correo: "correo" (no "email")
    
    Los tokens JWT incluyen:
    - idusuario
    - correo
    - nombre
    - idrol
    - nombrerol
    - iat (issued at)
    - exp (expiration)

    Para acceder en rutas protegidas:
    - req.usuario.idusuario
    - req.usuario.correo
    - req.usuario.nombrerol
    - req.token (JWT completo)
